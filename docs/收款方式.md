# 放置收款方式

## 在 README 展示微信或支付宝二维码

1. 从微信或支付宝保存你准备用于公开收款的二维码图片。需要的是收款码，不是付款码或登录码。
2. 将图片放入仓库的 `assets/donate/`。建议命名为 `wechat.png` 和 `alipay.png`；只有一种收款方式时只上传对应图片。
3. 编辑仓库根目录的 `README.md`，找到 `DONATION_QR_START` 与 `DONATION_QR_END` 两行注释，在它们之间加入下面的内容。

```html
<p>
  <img src="assets/donate/wechat.png" alt="微信收款码" width="220" />
  <img src="assets/donate/alipay.png" alt="支付宝收款码" width="220" />
</p>
```

只有一种方式时删除另一行 `<img>`。如果实际文件是 JPG，文件名和引用扩展名都改成 `.jpg`。图片上传并提交 README 后，打开仓库首页检查显示，再用另一台设备试扫确认收款人。

可以通过 GitHub 的文件上传功能直接完成，也可以把图片放到本地目录后用 Git 提交并推送。GitHub 会公开显示这些图片，上传前确认图片上展示的是你愿意公开的信息。

## 可选：在仓库显示 Sponsor 按钮

如果已有爱发电、Ko-fi 等平台的公开赞助页面，或者自己的公开收款说明页，可以创建 `.github/FUNDING.yml`，使用 `custom` 指向那个页面。把下面的示例网址换成你自己的实际链接后再提交：

```yaml
custom: ["https://example.com/support"]
```

`custom` 应填写可以访问的网页链接，不能填本地文件路径。没有开通 GitHub Sponsors 时，不要仅因为有 GitHub 用户名就填写 `github:`。只有二维码时，在 README 中展示即可，不必添加 Sponsor 按钮。

参考：[GitHub 官方 Sponsor 按钮说明](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/displaying-a-sponsor-button-in-your-repository)。
