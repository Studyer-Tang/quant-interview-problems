# 编译说明

两套源文件分别位于 `src/zh/` 和 `src/en/`，入口均为 `main.tex`。使用含 XeLaTeX 的 TeX Live 或 MacTeX。

以中文版为例，在仓库根目录运行：

```sh
cd src/zh
xelatex -interaction=nonstopmode -halt-on-error main.tex
xelatex -interaction=nonstopmode -halt-on-error main.tex
```

英文版在 `src/en/` 中运行同样的命令。按编译提示继续运行，直至目录和交叉引用稳定。生成的 `main.pdf` 位于各自源文件目录。

`main.tex` 控制版式，`cover.tex` 控制封面，`book-1.tex` 至 `book-6.tex` 组织章节。`section-notes/` 存放各节要点与方法，`parts/` 与 `classics-*.tex` 存放例题；`original-practice/` 与 `original-answers/` 存放精选小节练习和答案。书末答案由 `answers-1.tex` 至 `answers-6.tex` 组织。

所需宏包包括 ctex、fontspec、newtxtext、newtxmath、amsmath、mathtools、geometry、fancyhdr、titlesec、hyperref、needspace、tikz、enumitem、microtype、booktabs 和 longtable。正文使用的 Fandol、TeX Gyre、Latin Modern 字体由 TeX 发行版提供；封面字体和许可证在各语言目录的 `fonts/` 中。

题号用于 PDF 书签、交叉引用及练习与答案的双向链接。编辑题目后，请检查对应编号与引用，再重新编译 PDF。
