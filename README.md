# 量化笔试习题集

**作者：ttqqj**

这份习题集整理了我过去两年准备和参加 Quant 面试时积累的题目。我对题目做了分类、整理和改写，也补充了一些经典例题、解题方法与练习，现在无偿分享出来，希望能给同样在准备量化面试的朋友一些帮助。

接下来，我会继续深造，因此不再更新最新的面试题目。希望这份积累能在大家需要的时候派上用场。

祝大家学业顺利、就业顺利，也祝生活顺心！

## 内容

全书包括概率计算、随机过程、统计与线性代数、数学推理、算法与编程、综合练习六部分。共 23 个小节、230 道题；各节开头整理要点与方法，例题附详细解答，小节练习与其他练习的答案统一放在书末。
