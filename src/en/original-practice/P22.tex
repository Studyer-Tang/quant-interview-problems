\exercise{OP22}{Stopping an Alternating Sequence}
Generate independent $U_1,U_2,\ldots\sim\operatorname{Unif}(0,1)$ and require
\[
U_1<U_2>U_3<U_4>U_5<\cdots.
\]
Stop as soon as a newly generated value violates the required alternating inequality. Let $T$ count all generated values, including the final violating one. Find $\E T$.
